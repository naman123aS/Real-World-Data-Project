# Real-world Data Project (Retail Sales Analysis)

## Overview

This project focuses on analyzing real-world retail sales data to understand sales patterns, category performance, and business insights using Python data analysis techniques.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

## Features

- Data analysis on retail dataset
- Statistical summaries
- Sales trend analysis
- Category comparison
- Data visualization
- Correlation analysis

## Dataset Information

The dataset includes:

- Month
- Product Category
- Sales Amount
- Profit
- Orders

## Visualizations Used

- Line Chart
- Bar Graph
- Histogram
- Correlation Heatmap
